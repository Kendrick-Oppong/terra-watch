# Static Data

This folder contains static geospatial data used by the TerraWatch platform for seeding reference layers and enabling spatial analysis.

## Files

- `ghana-rivers.geojson` — river and stream network data.
- `ghana-communities.geojson` — community and settlement points.
- `study-areas/` — study area boundaries for configured monitoring regions.

> These files are placeholders and should be replaced with real geographic data for production use.
